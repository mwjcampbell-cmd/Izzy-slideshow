To load photos from a Google Drive folder, you’ll need a Google API key (Drive API enabled). This app only reads the folder list — it never uploads anything.

How do I create the API key?
  1. Go to Google Cloud Console → APIs & Services.
  2. Create a project (or use an existing one).
  3. Enable “Google Drive API”.
  4. Create Credentials → API Key.
  5. (Optional) Restrict the key to your GitHub Pages domain later.
